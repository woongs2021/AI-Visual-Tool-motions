# 앱 백로그

만들 앱 목록입니다. IDE 에이전트는 상태가 `todo`인 행을 번호 순서대로 만들고, 다 만들면 `done`으로 바꿉니다(`prompts/02-batch-from-backlog.md`).

- **행 수:** 04–27은 대화에서 나온 "27개 정도"에 맞춰 빈칸으로 만든 행입니다. 실제 개수에 맞게 더하거나 지우세요.
- **최소 입력:** 칸은 많이 채울수록 결과가 원하는 쪽에 가까워집니다. 최소한 **이름과 목적**만 적으면 나머지는 에이전트가 제안해서 채웁니다.
- **id:** 영문 kebab-case로 씁니다. 파일 이름(`<id>.html`)이 됩니다.
- **액센트:** 앱마다 하나씩 정하고, 기존 앱과 겹치지 않게 고릅니다.
- **화면 구성:** 위에서 아래 순서로 쓰고, 기본 상태가 390 × 844에 스크롤 없이 들어갈 분량으로 정합니다(섹션 4–6개 정도).
- **인터랙션:** 버튼, 상태 전환, 시트, 탭 등 실제로 동작해야 하는 것을 적습니다.
- **상태:** `todo` → `doing` → `done`
