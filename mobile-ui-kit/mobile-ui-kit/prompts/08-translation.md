# 08 · 한국어 번역 넣기 · 검수

새 앱이나 상세 화면을 만든 뒤, 또는 번역이 어색할 때 붙여 넣으세요. 규칙은 `CLAUDE.md`의 "언어 (한국어·영어)" 절에 있습니다.

---

[입력]
- 대상: (예: `habit-tracker` 앱 전체 / `pc-health-part.html` / 전체)
- 요청: (예: 새로 만든 화면 번역 / 이 문구를 더 자연스럽게: "…" → "…")

[작업]
1. 서버를 띄우고(`npm start` 또는 `python3 -m http.server 8080`) `npm run i18n-check -- --app=<id>`를 실행해 빠진 문구를 확인한다. 대상이 전체면 `--app` 없이 실행한다.
2. 빠진 문구를 `scripts/i18n/ko.js`에 넣는다.
   - 고정 문장 → `strings`에 넣는다. 영어 원문을 키로 그대로(따옴표·말줄임표 `…`·곱표 `×`까지 똑같이) 쓴다.
   - 숫자·이름·날짜·상태가 섞인 문장 → `patterns`에 정규식으로 넣는다. 잡은 부분은 `t()`로 다시 번역하고, 조사는 `josa(word, '을', '를')`로 붙인다. 구체적인 패턴을 위에, 넓은 패턴(` · `, ` — ` 분리)은 맨 아래에 둔다.
   - 제품명·모델명·코드·URL → `keep`에 넣는다(번역 안 함).
   - 화면 코드에 언어 분기를 넣지 않는다. JS가 만든 문구도 영어로 두면 사전이 바꾼다. 검색·정렬처럼 번역된 글자가 필요하면 `AUKit.i18n.t()`를 쓰고 `au:lang`에서 다시 그린다.
3. 말투를 맞춘다: 문장은 해요체("점검을 시작할 수 있어요"), 버튼·레이블·상태는 짧은 명사형("점검 시작", "합의됨"). 앱 이름은 영어 그대로, 사람 이름은 기존 표(Mina 미나, Joon 준, Sarah 서연, Daniel 도윤, Priya 하은, Alex 지호)를 따른다. 금액은 "580만 원", 날짜는 "11월 18일" 형식.
4. `npm run i18n-check`가 `✓ everything is translated (ko)`로 끝날 때까지 반복한다.
5. `index.html` → Language: 한국어 → 라이트·다크 각각 Run check로 390×844 검사를 통과시킨다. 한국어가 길어서 넘치면 문구를 줄인다(레이아웃을 바꾸는 건 마지막 수단).
6. `node scripts/capture.mjs --theme=both --lang=ko --app=<id>`로 캡처해 PNG를 직접 열어 확인한다: 어색한 줄바꿈, 잘림, 한 글자만 다음 줄로 넘어간 곳, 영어가 남은 곳.
7. 영어로 돌아갔을 때도 그대로인지 확인한다(`?lang=en`). `npm run walkthrough`가 통과해야 한다.

[결과 보고]
- 추가한 문구 수(strings / patterns / keep), 바꾼 표현, 검사 결과, 확인한 캡처 파일명.
