## [지시] 검수
`<id>` 앱을 점검하세요. **아직 고치지 말고** 문제 목록부터 보고합니다.

1. `node scripts/capture.mjs --theme=both --app=<id>`로 PNG를 뽑아 모든 상태를 눈으로 확인합니다.
2. index.html에서 Light와 Dark 검사를 실행합니다.
3. 아래 기준으로 문제를 찾아 **심각도순**으로 정리합니다. 각 문제에는 위치(파일:줄)와 고칠 방법 한 줄을 붙입니다.
   - 레이아웃: 겹침, 잘림, 화면 밖으로 나감, 스크롤 필요, 정렬이 틀어짐, 여백이 불균형함
   - 시각 위계: 히어로 요소가 여러 개, 강조 과다, 색 남용, 장식 요소
   - 다크 모드: 묻히는 요소, hex 하드코딩, 대비 부족(본문 4.5:1, 큰 글자·UI 3:1)
   - 동작: 안 되는 버튼, 상태가 안 바뀜, `reset`/`apply` 누락, Esc로 시트가 안 닫힘
   - 접근성: 44px 미만, 이름 없는 컨트롤, 잘못된 role, `aria-*`가 갱신 안 됨, 포커스가 안 보임
   - 데모 표시: 실제 측정이나 AI 결과로 오해될 수 있는 수치가 있음
   - 일관성: 다른 앱과 다른 앱 바·버튼·간격·타입

## [지시] 수정

- 고친 뒤 검사(Light와 Dark)와 캡처를 다시 하고, 고치기 전과 후를 짧게 보고합니다.
