# 01 · 새 앱 1개 만들기

> 아래 **[입력]**만 채워 IDE 에이전트에게 붙여 넣으세요. `apps/backlog.md`에 이미 적어 둔 앱이면 "backlog의 07번 앱을 만들어줘"라고만 써도 됩니다. 에이전트가 이 파일과 백로그를 함께 읽습니다.

---

## [입력]
- 번호: `04`
- id (kebab-case, 파일 이름이 됨): `habit-tracker`
- 앱 이름 (앱 바 제목): `Habit Tracker`
- 목적 (한 줄): 매일 지킬 습관과 연속 기록을 관리
- 핵심 사용자 상황: 아침에 오늘 할 습관을 확인하고 체크한다
- 액센트 컬러: `#F97316`
- 화면 구성 (위 → 아래):
  1. 상단: 뒤로가기 + 제목 + 메뉴
  2. 오늘 진행률 링 (3/5) + "3 of 5 done"
  3. 습관 리스트 5개 — 아이콘, 이름, 연속 일수, 체크 버튼
  4. 이번 주 7일 히트맵 (요일별 완료 수)
  5. 하단 주요 버튼: Add Habit
- 인터랙션: 체크/해제 → 진행률·연속 일수 변경, 습관 상세 시트, Add Habit 시트(이름 입력 → 리스트 추가), 초기화
- 데모로 표시할 것: 연속 일수와 히트맵은 샘플 데이터 (DEMO 태그)
- 캡처할 상태: 기본(3/5) · 전부 완료(5/5) · 상세 시트 · 추가 시트
- UI 문구 언어: English

---

## [지시]
`CLAUDE.md`(또는 `AGENTS.md`)의 규칙과 `prompts/00-project-brief.md`의 디자인 기준을 지켜 위 앱을 만드세요.

1. **생성:** `node scripts/new-app.mjs <id> "<앱 이름>" "<액센트>" "<목적>" --num=<번호>`
   - 출력된 대비 값을 확인합니다. 액센트 규칙(hex)은 생성된 그대로 둡니다.
2. **마크업** (`<id>.html`)
   - 화면 구성 순서대로 `<main class="au-content">`를 채웁니다. 공통 컴포넌트를 먼저 쓰고(카드, 행, 배지, 진행바, 세그먼트, 시트, 아이콘), 새로 필요한 모양만 `styles/apps/<id>.css`에 접두사 클래스로 만듭니다.
   - 시트는 생성된 메뉴 시트를 복제해서 `id`와 `aria-labelledby`를 바꿉니다.
   - 데이터 시각화(링, 파형, 히트맵, 차트)는 인라인 SVG나 CSS로 그리고, 색은 `var(--au-accent)`와 상태 톤 토큰만 씁니다.
3. **로직** (`scripts/apps/<id>.js`)
   - `DEFAULTS`에 데모 데이터를 넣고, `actions`(버튼마다 `data-action`), `reset()`, `apply(params)`를 구현합니다.
   - `apply`는 캡처할 상태를 URL 쿼리로 재현해야 합니다(예: `?all=1`, `?sheet=detail`).
   - 상태가 바뀌면 화면에 보이는 값, `aria-*`(valuenow, checked, expanded, selected), 스크린리더 안내(`announce`)를 함께 갱신합니다.
4. **등록:** `apps/registry.js`에서 이 앱의 `states`(라벨 + 쿼리)와 `notes`(무엇을 캡처하는지)를 채웁니다.
5. **검증:** `CLAUDE.md`의 "검증" 절차를 그대로 따릅니다.
   - index.html에서 Light와 Dark 모두 Pass가 나와야 합니다.
   - `node scripts/capture.mjs --theme=both --app=<id>`로 나온 PNG를 열어 직접 확인합니다.
   - 기본 상태가 스크롤 없이 들어가지 않으면 문구를 줄이거나 간격(8px 단위)과 크기를 조정합니다. 공통 토큰은 바꾸지 않습니다.
6. **마무리:** `apps/backlog.md`의 상태를 `done`으로 바꾸고, 바꾼 파일 목록과 검사 결과를 짧게 보고합니다.

## 품질 기준 (01–03 수준)
- 첫눈에 "실제 출시된 앱"처럼 보여야 합니다. 그러려면 시각적 위계(큰 숫자 하나, 보조 정보는 muted), 정렬, 넉넉한 여백이 필요합니다.
- 빈 화면이 생기지 않게 하고, 기본 상태에서 화면 아래쪽이 휑하지 않게 배치합니다.
- 다크 모드에서 어둡게 묻히는 요소가 없어야 합니다. 테두리·트랙·약한 배경은 토큰(`--au-border`, `--au-track`, `--au-bg-weak-alpha`)을 쓰면 자동으로 맞춰집니다.
- 숫자에는 `font-variant-numeric: tabular-nums`(`au-num`)를 씁니다.

[번역]
- 화면이 끝나면 `prompts/08-translation.md` 순서대로 `scripts/i18n/ko.js`에 한국어를 넣고 `npm run i18n-check`를 통과시킨다. 한국어로도 390×844 검사를 통과해야 완료다.
